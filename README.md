## About Me

I'm a **Full-Stack Developer** and CS student at Kafr el-Sheikh University. I build modern web applications with **React**, **Next.js**, **TypeScript**, and **Tailwind CSS**, backed by **Supabase** for authentication, real-time databases, and role-based access control. I started with strong C++ and problem-solving foundations, and I now focus on shipping clean, type-safe, fast, and responsive products end to end.

- Building full-stack apps with Next.js and Supabase (auth, database, storage, and RLS)
- Designing role-based systems with separate student, instructor, and admin experiences
- Writing type-safe code with TypeScript and styling quickly with Tailwind CSS
- Problem-solver at heart — C++ background sharpens my thinking
- Focused on clean, readable, and maintainable code
